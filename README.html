使用教學

Usage Guide

1

執行掃描

Run Scan

在終端機中執行 sysapp-tui，工具將自動並行掃描所有已安裝的套件、應用程式與工具鏈。

Run sysapp-tui in your terminal. It will automatically scan all installed packages, applications, and toolchains in parallel.

2

瀏覽儀表板

Browse Dashboard

掃描完成後自動進入 TUI 儀表板。使用 ↑↓ 瀏覽清單，按 1–6 切換排序方式。

The TUI dashboard launches automatically after scanning. Use ↑↓ to navigate, press 1–6 to change sorting.

3

搜尋與篩選

Search & Filter

按 / 進入搜尋模式，輸入關鍵字即時過濾。支援套件名稱比對（不分大小寫）。

Press / to enter search mode. Type keywords to filter in real-time (case-insensitive name matching).

4

檢視詳細資訊

View Details

選取任一項目後按 i，檢視包括版本、來源、語言、安裝日期、使用次數與路徑等完整資訊。

Select an entry and press i for full details: version, source, language, install date, usage count, and path.

去重邏輯

Deduplication Logic

高優先級 → 低優先級

Higher → Lower Priority

高優先級來源取代低優先級來源，但會保留低優先級來源中高優先級缺少的欄位（如路徑、描述、安裝日期）

Higher-priority sources replace lower ones, but retain fields missing from the higher source (path, description, install date)

低優先級 → 高優先級

Lower → Higher Priority

低優先級來源僅填補高優先級來源的空缺欄位，不覆蓋既有資料

Lower-priority sources only fill gaps in higher-priority data, never overwrite

語言識別

Language Identification

  1. 第一階段：依據來源直接推斷（cargo → Rust、pip → Python、npm → JS、go → Go、gem → Ruby）
  2. Stage 1: Infer directly from source (cargo → Rust, pip → Python, npm → JS, go → Go, gem → Ruby)
  3. 第二階段：對 Homebrew 二進位檔執行 file 命令分析
  4. Stage 2: Run file on Homebrew binaries to detect language
  5. 第三階段：對 .app 套件檢查內含的 framework 類型
  6. Stage 3: Inspect .app bundles for embedded framework types

使用資料

Usage Data

  • CLI 工具：解析 ~/.zsh_history，統計各指令出現次數
  • CLI tools: Parse ~/.zsh_history, count command occurrences
  • GUI 應用程式：透過 mdls 查詢 Spotlight 中記錄的最後使用時間與使用次數
  • GUI apps: Query mdls for Spotlight's last-used timestamps and usage counts
